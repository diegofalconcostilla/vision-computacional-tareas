> **Nota.** Es material de un curso, publicado como portafolio y referencia. Si lo consultas como estudiante, cita la fuente y respeta las normas de integridad académica de tu institución.

## Estructura

- `actividades/NN-…/`: informe en PDF, `construir.py` (prácticas: extiende y ejecuta el notebook) o `experimentos.py` + `informe.py` (análisis), `figuras/` y `resultados.json` con las métricas.
- `herramientas/`: utilidades compartidas: generación de informes PDF (`reporte.py`) y Word (`word.py`), ejecución de notebooks (`cuaderno.py`), descarga de imágenes con licencia verificada (`commons.py`) y evaluación de detectores de puntos clave (`puntos.py`).
- `datos_compartidos/`: banco de imágenes libres y `LICENCIAS.md` con autor, licencia y fuente de cada una.

## Cómo reproducir

```bash
pip install -r requirements.txt
cd actividades/17-relaciona-otsu-camscanner
python experimentos.py      # figuras y resultados.json
python informe.py           # PDF + .docx (requiere Edge o Chrome, y pandoc para el .docx)
```

Las prácticas se regeneran con `python construir.py` dentro de su carpeta. Sus `.docx` se generan desde los notebooks ya ejecutados, sin volver a correrlos: `python -m herramientas.word` (desde la raíz). El Word es una conversión del mismo contenido para facilitar la edición; el diseño puede diferir un poco del PDF. Los notebooks base originales del curso no se incluyen: los notebooks entregados los amplían y los ejecutan localmente. Algunos scripts usan la fuente `arial.ttf` (Windows) para generar texto de prueba.
